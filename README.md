# Sales Dashboard (Power BI)

## Overview
A company-wide sales performance dashboard built to analyse revenue, profit, and sales trends.

## Tools Used
- Power BI Desktop

<img width="1168" height="647" alt="image" src="https://github.com/user-attachments/assets/bd9aa9b9-ebec-4c95-92b5-e7fe0c7d7867" />

## What I Built
- KPI cards showing Revenue, Profit, Profit Margin, Quantity and Transactions
- Sales trends by year
- Sales breakdown by country, customer segment and region
- Top customers by revenue

## Process
- Performed data modelling to structure the dataset
- Created a date table to support time-based analysis
- Built DAX measures for key metrics
- Designed the report layout and visuals
